## Push to GitHub
Create an empty repository on GitHub (do not add a README/license there), then run these commands in this folder's terminal:

```bash
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
git push -u origin developer2
```
